# Зоопарк «Ковчег» — демо-сайт

Демо-проект для портфолио. Зоопарк вымышленный: оплата, звонки и формы показывают плашку «Пробный сайт» со ссылкой на Telegram @isthisthedaggr.

## Запуск на компьютере

Нужен Node.js. В этой папке:

```
node serve.mjs
```

Сайт откроется по адресу http://localhost:5190

## Что внутри

- `index.html` и ещё 12 страниц — сайт
- `js/kovcheg.js` — общий движок страниц (корзина хранится в браузере, общая для всех страниц)
- `img/` — фото с Wikimedia Commons (CC BY, CC BY-SA, CC0, PD)
- `serve.mjs` — локальный сервер для просмотра

Для хостинга подойдёт любой статический хостинг (GitHub Pages, Netlify, Vercel): загрузить содержимое папки, `serve.mjs` не нужен.
